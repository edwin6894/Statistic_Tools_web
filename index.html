User Guide

Navigation

  • Left Sidebar : Grouped menus for all calculators
  • Mean : Simple, Geometric, Harmonic, Weighted, plus Frequency Distribution versions
  • Median : Simple, Discrete Frequency Distribution, Grouped Data
  • Mode : Simple, Discrete Frequency Distribution, Grouped Data
  • Graphs: Generation of Graphs such as Bar, Double Bar, Pie chart, Line , Box plot, Polar

How to Use

  • Select a calculator from the left sidebar
  • Enter your data using spaces or commas
  • Press Calculate or press Enter
  • For Frequency Distribution calculators, click Save to Excel to export data
  • Use Reset to clear the current calculator
  • Switching calculators automatically resets previous values
  • For Graphs: Press Generate to create graphs within the web page itself and use save as option to save the graph to your desired device
