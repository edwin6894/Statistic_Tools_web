User Guide

Navigation

  • Mean : Simple, Geometric, Harmonic, Weighted, plus Frequency Distribution versions
  • Median : Simple, Discrete Frequency Distribution, Grouped Data
  • Mode : Simple, Discrete Frequency Distribution, Grouped Data
  • Dispersion : Range, MAD, Variance, Std Dev, CV
  • Quartiles : Quartiles, Five-Number Summary, Percentiles
  • Correlation & Regression : Correlation Coefficient, Linear Regression
  • Skewness & Kurtosis : Skewness, Kurtosis
  • Visualizations : Build customized graphs, Histograms, Scatter Plots, and Polygons seamlessly

How to Use

  • Select a calculator from the left sidebar
  • Enter your data using spaces, commas, or both
  • Press Calculate or press Enter
  • Use Reset to clear the current calculator
  • Use Export to download Excel sheets for Frequency Distribution data
